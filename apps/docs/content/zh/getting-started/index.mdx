Magic Resume 有两种运行模式：自托管模式适合改造代码，部署自己的多租户 Magic Resume 则需要带 Clerk 和 Core API 的云端模式。只是想用产品，可以直接访问托管版 [magic-resume.cn](https://magic-resume.cn)。

## 怎么在本地快速启动？

```bash
git clone https://github.com/LinMoQC/Magic-Resume.git
cd Magic-Resume
pnpm install
cp apps/web/.env.example apps/web/.env.local
pnpm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 访问应用。（本文档是独立的 Mintlify 站点，在 `apps/docs/content` 里用 `npx mint dev` 本地预览。）

## 我该选哪种模式？

| 你想做的事 | 模式 |
|---|---|
| 改造代码本身 | **自托管** —— 依赖最少 |
| 部署你自己的多租户 Magic Resume | **云端** —— 需要 Clerk 和 Core API |
| 试用 MCP 集成 | 都行，但云端更省事（不用自己部署 Core API） |
| 只是想用产品 | 直接访问托管版 [magic-resume.cn](https://magic-resume.cn) |
