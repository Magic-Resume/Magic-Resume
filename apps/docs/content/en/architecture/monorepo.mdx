Public package sources and releases live in [magic-resume-kit](https://github.com/Magic-Resume/magic-resume-kit). Source paths and package build commands for schema, templates, design-system, icons, utils and MCP on this page refer to that repository. Applications consume `@magic-resume-kit/*` from npm.

Magic Resume is a **pnpm + Turborepo** monorepo. The root `package.json` pins the package manager to `pnpm@10.28.1` so CI and local installs stay aligned.

## What workspaces are available?

| Path | Package name | Role |
|---|---|---|
| `apps/web` | `@magic-resume/web` | Next.js 16 App Router frontend. The actual product. |
| `apps/docs/content` | — | This site. Mintlify (Markdown/MDX, no build step). |
| kit: `packages/mcp` | `@magic-resume-kit/mcp` | stdio MCP server + CLI. Node ESM, published to npm. |
| kit: `packages/resume-schema` | `@magic-resume-kit/resume-schema` | Zod schema, types, sample data, JSON Schema export. |
| kit: `packages/resume-templates` | `@magic-resume-kit/resume-templates` | Template DSL, renderer, registry. |
| kit: `packages/utils` | `@magic-resume-kit/utils` | Cross-workspace utilities (cn, color, logger, time). |
| `apps/landing` | `@magic-resume/landing` | Astro |
| `packages/genui` | `@magic-resume/genui` | AI Lab widgets |
| `packages/tsconfig` | `@magic-resume/tsconfig` | Shared TypeScript configs. |

## What are the package dependency boundaries?

These are enforced by code review rather than tooling. Keep them honest:

<Warning>
**`@magic-resume-kit/mcp` must not import from:**
- Next.js or React component packages
- Browser APIs (`window`, `localStorage`, `IndexedDB`)
- Anything in `apps/web`

It's a plain Node ESM library + CLI. Adding a browser import will break `node --test` and `npm publish`.
</Warning>

- `apps/web` may depend on any `packages/*` workspace.
- `packages/resume-templates` depends on `packages/resume-schema`. The reverse must not happen — schema is the leaf.
- `packages/mcp` depends on `packages/resume-schema` and `packages/resume-templates`. Not on `apps/*`.
- New shared shapes belong in `packages/resume-schema`, not duplicated into `apps/web`.

## How do I run commands with Turborepo?

The root `package.json` runs everything through Turbo:

```bash
pnpm run dev     # turbo dev    — every workspace's dev script in parallel
pnpm run build   # turbo build  — respects task dependencies
pnpm run lint    # turbo lint
pnpm run test    # turbo test
```

To target one workspace, skip Turbo and use a pnpm filter:

```bash
pnpm --filter @magic-resume/web dev
pnpm --filter @magic-resume/genui build
```

## How does the `workspace:*` protocol work?

Local cross-workspace deps use the `workspace:*` protocol in `package.json`. This means **you must run `pnpm install` from the repo root**, not from inside a workspace, or pnpm can't resolve the link.

When you publish `@magic-resume-kit/mcp`, pnpm rewrites `workspace:*` to the real version at pack time — no manual bumping needed.

Applications pin exact npm versions for `@magic-resume-kit/*`; only local packages such as GenUI use `workspace:*`. Public package releases are handled by GitHub Actions in magic-resume-kit.
