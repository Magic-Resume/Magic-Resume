This page collects common whole-repo (Turbo), single-workspace (pnpm filter), and MCP CLI commands. All paths are relative to the repo root.

## How do I run whole-repo commands with Turbo?

```bash
pnpm install      # install all deps, resolve workspace links
pnpm run dev      # turbo dev — every workspace's dev script
pnpm run build    # turbo build — respects task dependencies
pnpm run lint     # turbo lint
pnpm run test     # turbo test
```

## How do I run single-workspace commands with pnpm filter?

```bash
pnpm --filter @magic-resume/web dev
pnpm --filter @magic-resume/web build
pnpm --filter @magic-resume/web lint
pnpm --filter @magic-resume/web i18n:check

cd apps/docs/content && npx mint dev            # this docs site (Mintlify local preview)

```

Run these public-package commands from the [magic-resume-kit](https://github.com/Magic-Resume/magic-resume-kit) repository root:

```bash
pnpm --filter @magic-resume-kit/resume-schema build
pnpm --filter @magic-resume-kit/resume-schema test  # node --test

pnpm --filter @magic-resume-kit/resume-templates build

pnpm --filter @magic-resume-kit/mcp build
pnpm --filter @magic-resume-kit/mcp test
pnpm --filter @magic-resume-kit/mcp lint            # tsc --noEmit
```

## What MCP CLI commands are available after installation?

```bash
npx -y @magic-resume-kit/mcp config set --api-url <url> --pat <token>
npx -y @magic-resume-kit/mcp config print
npx -y @magic-resume-kit/mcp config clear
npx -y @magic-resume-kit/mcp mcp                    # boot stdio server
```

## What one-off commands are useful?

```bash
# Run in magic-resume-kit: rebuild the JSON Schema artifact only
pnpm --filter @magic-resume-kit/resume-schema build

# Return to Magic-Resume for the web app bundle analyzer
pnpm --filter @magic-resume/web analyze

# Production build of the web app
pnpm --filter @magic-resume/web build:prod
```

## What checks do Husky and lint-staged run automatically?

These run automatically on `git commit`:

- ESLint with `--fix` on staged `*.{js,jsx,ts,tsx}`
- `i18n:check` on staged `apps/web` files
- Prettier on staged JSON / Markdown / YAML

To skip them in a true emergency: `git commit --no-verify`. But please don't.
