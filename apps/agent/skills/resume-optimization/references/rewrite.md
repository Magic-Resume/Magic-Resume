# Rewrite checks

Keep the actor, action, constraints and result distinguishable. Prefer specific verbs over adjectives. Preserve the difference between contributing and leading. Reuse a numeric result only with its original unit, baseline and time period. Never convert a team result into sole ownership. Do not add a tool merely because the job description names it.

Before writing, compare IDs, section keys, untouched fields, dates, employers, schools and credentials. Keep HTML valid and preserve links. A shorter statement is useful only if it retains the evidence needed to understand the work.
