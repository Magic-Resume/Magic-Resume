# 面试声音试听

2026-10-16：创建 Voice Agent 时可先试听当前选择的声音。样音通过现有 Lyra 语音渠道录制，没有使用已废弃的 TTS 链路。每段保留完整的同一句中文，去掉额外开场和头尾静音，统一音量后编码为单声道 48 kHz / 128 kbps MP3。

> 你好，我是你的面试搭档。放轻松，我们从你最熟悉的项目开始。

音频已上传到现有 Cloudflare R2 公共资源桶的 `interview/voice-previews/v1/`，文件名包含内容 SHA-256 前 16 位，缓存一年且 immutable。上传后逐个回读并核对完整 SHA-256。没有改动桶的 CORS 或已有对象。

前端清单位于 `apps/web/src/app/dashboard/interview/_components/voicePreviewSamples.json`。`levels` 是从每个最终 MP3 解码后按 40 ms 计算的 RMS（增益 8，量化为 0–15 的十六进制字符串）；播放器根据实际播放时间读取包络驱动同一颗球，不依赖跨域 Web Audio 分析或 React 逐帧更新。

进入页面不预下载音频；点击试听才读取选中的静态文件，不创建面试、调用模型或申请麦克风权限。再次点击、切换声音、进入面试、切换到后台或离开页面时停止并释放媒体。音频加载失败或 12 秒未开始时允许重试；旧播放的异步回调不能覆盖新选择。

录制原始文件和上传校验记录保存在本次本地工作资料 `/private/tmp/interview-voice-samples/`，不含账号凭据。未来替换样音时，从相同渠道确认音色和语句，重新裁剪、编码、计算包络与哈希，并使用新内容哈希对象更新清单；不要原地覆盖 immutable 文件。上游语音效果升级后应重新录制匹配的样音。
