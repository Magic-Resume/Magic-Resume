## 最该先修

1. `请稍后重试` 系列兜底（12 处）覆盖登录、通知、设置、反馈、导出、套餐、全局错误，用户几乎必然撞上。
2. `您的` 22 处对 `你的` 190+ 处，同文件内语气断裂，替换风险极低。
3. `云端同步 / 云同步 / 同步中` 三套说法分布在侧边栏、设置页、顶栏、简历库。
4. 23 处「！」收尾（保存、导出、导入、复制、发布），与同界面其它无标点提示并列时观感最「营销味」。
5. 半角 `...` 94 处对全角 `…` 36 处，批量替换成本最低。
6. `X 部分已成功更新` 类名词句（编辑页每次操作都触发）。
7. `出了点问题 / 未知错误` 兜底三处，同屏可能同时出现。
8. AI 功能三套称呼：`模型`（设置页）、`大模型`（导入、错误码）、`智能体`（面试）。
9. 编辑态动词离散：`拒绝` / `丢弃` / `放弃` 描述同一动作。
10. `agent_run_failed` 通用码配 PDF 专用文案（已修）。

## 说明

`agent_run_failed` 在 `packages/util/src/errors.ts` 的 `LEGACY_CODE_ALIASES` 中被映射为一级码 `internal_error`，是**通用**的 run 失败码，任何非 PDF 的 agent 运行失败都会走到它。把它写成 PDF 专用文案，意味着一次改写或面试运行失败时会提示用户「换一份 PDF」。
